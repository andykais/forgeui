# Editor document → API graph golden cases

What `editorToApi` (`src/workflows/editor_graph.ts`) must agree with: ComfyUI's
own editor. One directory per case, each a template a stock ComfyUI 0.34 ships,
chosen for one rule of the conversion (the directory name says which):

- `editor.json` — the template as the editor saves it (`source.json` names it).
- `comfy_api.json` — what ComfyUI's frontend queued for it:
  `app.graphToPrompt()` run in a browser, by `scripts/editor_oracle.cjs`.
- `object_info.json` (shared) — that ComfyUI's node list, trimmed to the node
  types these cases use.

**These are not regenerated by `UPDATE_GOLDEN=1`.** The expected file is
ComfyUI's output, not ours: accepting our own would test nothing. To refresh a
case, run the oracle against a real ComfyUI (`deno task comfy:serve`):

```sh
NODE_PATH=tests/e2e/node_modules node scripts/editor_oracle.cjs http://127.0.0.1:8188 <templates dir> <out dir> <template name>…
```

The comparison is of what ComfyUI would run, not of bytes: only nodes an output
node needs, inputs the node declares (the editor sends a stray legacy key or
two, which ComfyUI ignores), numbers to 12 significant figures, and node ids up
to renaming (the editor renumbers subgraph nodes whose ids clash).

Run over every template a 0.34 install ships (514), the converter agrees on 502.
Of the other twelve, ten use widgets only the editor can fill (a painted canvas,
a rendered 3D view) and are reported as such; two hit editor quirks (a
`PrimitiveNode` reaching a subgraph through a `Reroute` is not applied; one
paid-API template where the editor puts a model name in an aspect-ratio input).
